# Rehabilia downloads

Installers of the rehabilitation application and the game packages it installs, published as
GitHub Releases. Nothing here is source code, and nothing here is ever patient data.

**Trial builds only, for now.** They are development builds of the non-medical variant, for
trying the platform on PCs outside the company. Their games are unsigned and are recorded as
`unverified` by the application. They are not a medical device release.

How the application reads this repository, and what the channels are, is decided in the
application's repository (ADR-0029, §8 step 3, and `docs/game-studio-briefing.md` §14).
